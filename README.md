# Tienda de Discos Nu Metal 🎸

API REST para gestionar una tienda de discos de nu metal.

## Instalación

1. Clona el repo
2. `npm install`
3. `npm start`

## Rutas disponibles

- `GET /discos` - Obtener todos los discos
- `POST /discos` - Crear un disco nuevo
- `GET /discos/:id` - Obtener un disco por ID
- `DELETE /discos/:id` - Eliminar un disco
